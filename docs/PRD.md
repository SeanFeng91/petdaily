# PetDaily PRD

## 1. 产品定位

PetDaily 是一个手机优先的宠物日常管理和交流型 App。MVP 聚焦一只 3 个月西高地幼犬的养育记录闭环，帮助主人持续记录、回看、理解和优化日常照护节奏。

第一版不做医疗诊断，也不直接替代兽医。AI 的职责是把主人输入的饮食、排便、如厕、体重、疫苗驱虫、费用和照片记录整理成可执行的养育建议。

中长期版本会探索狗叫声检测和声学智能，但必须以主人校准、概率判断和隐私保护为前提，不把声音模型输出当作确定性诊断。

## 2. 目标用户

- 刚接回幼犬的新手主人。
- 希望用手机快速记录日常、用 PC 查看图表和账本的人。
- 关注训练规律、健康观察和费用统计的长期养宠用户。

## 3. MVP 范围

### 已落地能力

- 宠物基础档案：名字、品种、性别、生日、当前体重、备注、头像。
- 时间日记：饮食、如厕、排便、体重、疫苗、驱虫、照片、备注。
- 时间轴首页：打开即展示连续事件流，支持按类型筛选和删除误记事件。
- 快捷事件：常用事件按钮和数字键 `1-9` 触发，支持在「我的」配置名称、类型、默认数值和备注。
- 快速记录：底部弹层选择类型、填写数值/时间/备注，并支持拍照、读取相册或粘贴图片 URL。
- 体重追踪：体重记录、趋势图，并支持已有条目修改和删除。
- 提醒计划：喂食、外出如厕、训练、疫苗、驱虫等应用内提醒列表。
- 照片成长墙：保存图片 URL/Data URL、说明和时间。
- 费用账本：品类、物品、金额、日期、统计图，并支持已有条目修改和删除。
- AI 养育教练：无 API key 时用本地规则建议；有 API key 时从服务端调用在线模型。
- 手机/PC 响应式：手机底部导航，桌面左侧导航和宽图表。

### 暂不纳入 MVP

- 多宠物、多家庭成员协作。
- 原生系统推送、短信、微信通知。
- R2/对象存储级文件上传。
- 狗叫声长期后台监听、音频片段存储和模型训练闭环。
- 社区分享、公开动态和好友评论。
- 医疗诊断、用药决策和异常病症结论。

### 后续声学智能范围

- 狗叫检测：手机前台运行时监听环境音，检测到疑似狗叫后自动生成时间线事件并进入声音库。
- 音频记录：只保存触发前后候选短片段，不保存全天连续录音。
- 人工校准：主人可以给一组相似声音批量标注“是/不是狗叫”和可能原因，例如无聊、想出去、想吃、害怕、寻求关注。
- 声学特征：沉淀响度、频谱变化、过零率、持续时间、音频 embedding 和模型版本，为后续个性化判断做准备。
- 意图预测：结合声音特征、喂食/外出/训练历史和主人反馈，输出概率和解释，不给确定性结论。
- 多模态辅助：后续接入摄像头，把狗的位置、姿态、朝向和场景线索作为辅助证据。

## 4. 核心页面

- 时间轴：首页事件流、快捷事件、类型筛选、AI 建议和提醒。
- 记录：完整时间日记和类型筛选视觉。
- 洞察：体重曲线、体重维护、费用图表、费用维护、AI 历史建议。
- 相册：成长照片墙和拍照/相册导入。
- 我的：快捷事件配置、宠物档案、提醒管理、Cloudflare 同步说明。

## 5. 成功标准

- 新用户 seed 后进入首页即可看到清晰时间轴和常用快捷事件。
- 10 秒内用快捷按钮完成一条喂食或如厕记录；30 秒内完成带照片或备注的完整记录。
- 能看到幼犬体重趋势、提醒和费用结构，并能维护错误条目。
- AI 在无网络 key 时也能返回有解释的本地建议。
- 数据模型可迁移到 Cloudflare D1/R2，而不需要推翻页面和 API。
- 声学智能阶段能形成“检测 -> 记录 -> 标注 -> 校准 -> 分析”的闭环，而不是只做一个录音按钮。

## 6. 风险与约束

- 幼犬健康建议必须保守，所有健康文本都提示不能替代兽医诊断。
- 照片第一版是浏览器压缩后的 Data URL 或外部 URL，真实对象存储需要 R2 阶段接入。
- 当前默认单人单宠，多宠物会影响导航、权限和汇总逻辑。
- Web/PWA 形态不能可靠承诺锁屏后台长期录音；狗叫监听第一阶段必须写明“前台运行”约束，真正无人值守需要原生 App 或固定采集设备。
