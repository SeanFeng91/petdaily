# PetDaily PRD

## 1. 产品定位

PetDaily 是一个手机优先的宠物日常管理和交流型 App。MVP 聚焦一只 3 个月西高地幼犬的养育记录闭环，帮助主人持续记录、回看、理解和优化日常照护节奏。

第一版不做医疗诊断，也不直接替代兽医。AI 的职责是把主人输入的饮食、排便、如厕、体重、疫苗驱虫、费用和照片记录整理成可执行的养育建议。

## 2. 目标用户

- 刚接回幼犬的新手主人。
- 希望用手机快速记录日常、用 PC 查看图表和账本的人。
- 关注训练规律、健康观察和费用统计的长期养宠用户。

## 3. MVP 范围

### 已落地能力

- 宠物基础档案：名字、品种、性别、生日、当前体重、备注、头像。
- 时间日记：饮食、如厕、排便、体重、疫苗、驱虫、照片、备注。
- 快速记录：底部弹层选择类型、填写数值/时间/备注/照片路径。
- 体重追踪：体重记录和趋势图。
- 提醒计划：喂食、外出如厕、训练、疫苗、驱虫等应用内提醒列表。
- 照片成长墙：保存照片 URL/路径、说明和时间。
- 费用账本：品类、物品、金额、日期和统计图。
- AI 养育教练：无 API key 时用本地规则建议；有 API key 时从服务端调用在线模型。
- 手机/PC 响应式：手机底部导航，桌面左侧导航和宽图表。

### 暂不纳入 MVP

- 多宠物、多家庭成员协作。
- 原生系统推送、短信、微信通知。
- 真正的文件上传和图片压缩。
- 社区分享、公开动态和好友评论。
- 医疗诊断、用药决策和异常病症结论。

## 4. 核心页面

- 今天：宠物状态、今日记录、AI 建议、提醒。
- 记录：完整时间日记和类型筛选视觉。
- 洞察：体重曲线、费用图表、AI 历史建议。
- 相册：成长照片墙和新增照片路径。
- 我的：宠物档案、提醒管理、Cloudflare 同步说明。

## 5. 成功标准

- 新用户 seed 后进入首页即可理解今天该做什么。
- 30 秒内完成一条喂食、如厕或体重记录。
- 能看到幼犬体重趋势、今日记录数量、提醒和费用总额。
- AI 在无网络 key 时也能返回有解释的本地建议。
- 数据模型可迁移到 Cloudflare D1/R2，而不需要推翻页面和 API。

## 6. 风险与约束

- 幼犬健康建议必须保守，所有健康文本都提示不能替代兽医诊断。
- 照片第一版是路径/URL 记录，真实上传需要 R2 阶段接入。
- 当前默认单人单宠，多宠物会影响导航、权限和汇总逻辑。
