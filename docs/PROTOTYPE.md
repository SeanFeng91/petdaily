# PetDaily 交互原型说明

## 信息架构

移动端底部导航包含 5 个一级入口：

- 今天：最高频入口，用于查看今日状态和快速记录。
- 记录：按时间线回看全部日常行为。
- 洞察：查看体重、费用和 AI 建议。
- 相册：照片成长墙。
- 我的：宠物档案、提醒和同步边界。

桌面端使用左侧导航，主区域扩展为更宽的图表和内容列表。

## 核心交互

### 1. 快速记录

入口位于「今天」首屏主按钮和「记录」页顶部按钮。点击后打开底部弹层：

- 选择记录类型：饮食、如厕、排便、体重、疫苗、驱虫、照片、备注。
- 填写标题、数值、时间和备注。
- 选择照片类型时可填照片路径。
- 保存后进入时间线；体重记录会同步进入体重曲线。

### 2. 今日教练建议

「今天」页展示 AI 教练建议。用户点击「生成今日建议」：

- 无 `OPENAI_API_KEY`：使用本地规则生成建议。
- 有 `OPENAI_API_KEY`：服务端基于宠物档案和最近记录生成建议。
- 生成结果写入 AI 建议历史。

### 3. 提醒计划

提醒以应用内计划列表呈现。用户可以新增提醒，也可以点击按钮启用/停用。系统推送保留到后续阶段。

### 4. 照片成长墙

用户输入照片路径或未来的 R2 URL，并填写说明。保存后出现在相册中；照片记录也可通过快速记录进入时间线。

### 5. 费用账本

用户选择品类、输入物品名和金额。费用进入列表并刷新费用结构图。

## 视觉原则

- 手机优先：主操作按钮足够大，底部导航稳定可触达。
- 工作台优先：界面直接展示记录、提醒和图表，不做营销式首页。
- 低噪声：少装饰、多留白、清晰标签。
- 幼犬友好：使用温和的绿色、玫红、蓝色和琥珀色区分行为类型。
