# PetDaily 使用说明

## 1. 初始化

本地开发：

```bash
npm install
cp .env.example .env
npm run db:push
npm run db:seed
npm run dev
```

访问 `http://127.0.0.1:3000`。

Cloudflare D1 上线：

```bash
nvm use
npx wrangler login
npm run cf:d1:create
```

把输出的 `database_id` 写入 `wrangler.jsonc` 后执行：

```bash
npm run cf:d1:migrate
npm run cf:d1:seed
npm run cf:deploy
```

部署完成后，用手机打开 Cloudflare 输出的线上 URL。线上数据会写入 D1，不依赖本机 `data/petdaily.db`。

## 2. 默认样例

seed 数据会创建一只 3 个月西高地幼犬「豆包」，并写入：

- 宠物档案和头像。
- 近两周体重记录。
- 喂食、如厕、排便、疫苗、驱虫和照片时间线。
- 喂食、外出如厕和驱虫提醒。
- 主粮、尿垫、玩具、医疗、护理费用。
- 一条初始 AI 建议。

## 3. 时间轴和日常记录

首页是「白板日记」主界面：最近事件在最前，标题下方是小型快捷事件，然后就是时间轴。可按类型筛选，也可以直接删除误记的条目。

常用事件可以用首页的「快捷事件」按钮一键记录；桌面键盘也可以按数字键 `1-9` 触发对应快捷项。进入「我的」里的「快捷事件」可以配置按钮名称、事件类型、默认数值和备注，配置会保存在当前浏览器。

需要更完整内容时，点击悬浮 `+` 打开记录弹层。

支持的记录类型：

- 饮食：建议填写克数。
- 如厕/排便：建议填写次数和状态。
- 体重：填写 kg，会同步体重曲线和当前体重。
- 疫苗/驱虫：记录时间和备注。
- 照片：可拍照、读取相册或填写图片 URL，进入时间线并保存为照片资产。
- 备注：记录训练、情绪、睡眠等观察。

删除初始模拟记录：在首页时间轴里删除对应条目。删除体重记录会重新计算当前体重；删除带照片的记录会同步移除关联照片资产。

## 4. AI 教练

在首页的建议区域点击「生成今日建议」。

- 没有配置 key 时，会返回本地规则建议。
- 配置 `.env` 中的 `OPENAI_API_KEY` 后，会从服务端生成建议。
- 所有健康相关建议不能替代兽医诊断。

## 5. 费用、体重和照片

- 「洞察」页可以新增、修改、删除费用，并查看统计图。
- 「洞察」页可以修改或删除已有体重条目；如果该体重来自时间线记录，会同步更新或移除对应时间线。
- 新增事件时可以点击「拍照」调用手机相机，或点击「相册」选择已有照片。
- 带图片的记录会在时间轴里显示缩略图，点击可以全屏浏览。
- 照片会在浏览器端压缩后保存到 Cloudflare D1。照片数量变多后，下一步建议迁移到 R2。

## 6. 提醒

「我的」页可以新增提醒、完成今天、暂停/启用、删除提醒。首页会显示提醒状态：

- 已到点：当前时间已经超过提醒时间，且今天尚未完成。
- 稍后：提醒时间还没到。
- 今日已完成：今天已经点过完成。
- 已暂停：提醒暂时不参与待办。

当前版本是应用内提醒，不做系统级推送；手机打开网页即可使用和同步。

## 7. iPhone 桌面 Web App 和微信

iPhone 推荐用 Safari 打开部署地址，点击分享按钮，选择「添加到主屏幕」。从桌面图标进入后，PetDaily 会使用独立 Web App 的 manifest、主题色和图标，减少浏览器地址栏对日常记录的干扰。

微信里直接打开网页时，微信浏览器顶部容器通常仍会存在。如果需要完全沉浸式微信入口，建议后续做微信小程序壳或原生小程序，并配置正式业务域名；当前 `workers.dev` 更适合作为部署验证地址，不适合作为最终微信业务域名。

## 8. 狗叫声检测规划

狗叫声检测已进入声音库 V2：手机保持 PetDaily 打开并不锁屏，进入「监听」，授权麦克风后开始检测疑似狗叫。命中后会保存候选短音频、自动记录到时间线，并进入声音库按相似 embedding 聚类。

当前版本不保存全天录音；只保存候选片段、触发时间、声学摘要、embedding、聚类状态和人工标签。你不需要逐条判断，可以先让它收集一批，再给同组样本批量标注“想出去”“不是狗叫”等原因。需要注意：普通网页或 PWA 不能可靠保证锁屏、后台或微信切走后的长期录音。真正全天无人值守监听需要后续做原生 App、Expo/React Native 壳，或固定家用采集设备。详细方案见 `docs/BARK_DETECTION.md`。

### 8.1 下载声音数据并训练模型

先确认已登录 Cloudflare，并使用项目要求的 Node 版本：

```bash
nvm use
npm run bark:model:download
```

下载后的数据在 `data/bark-sync/`：

- `samples.json`：候选片段、声纹特征、embedding、标签。
- `sessions.json`：连续叫声段。
- `clusters.json`：声音聚类。
- `audio/`：从 R2 拉下来的原始短音频。
- `audio-manifest.json`：每段音频是否下载成功。

本地训练并推回远程：

```bash
npm run bark:model:train
npm run bark:model:push
```

也可以一条命令完成：

```bash
npm run bark:model:sync
```
