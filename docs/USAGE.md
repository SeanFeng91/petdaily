# PetDaily 使用说明

## 1. 初始化

```bash
npm install
cp .env.example .env
npm run db:push
npm run db:seed
npm run dev
```

访问 `http://127.0.0.1:3000`。

## 2. 默认样例

seed 数据会创建一只 3 个月西高地幼犬「豆包」，并写入：

- 宠物档案和头像。
- 近两周体重记录。
- 喂食、如厕、排便、疫苗、驱虫和照片时间线。
- 喂食、外出如厕和驱虫提醒。
- 主粮、尿垫、玩具、医疗、护理费用。
- 一条初始 AI 建议。

## 3. 日常记录

进入「今天」或「记录」，点击「记录刚发生的事」或「新增记录」。

支持的记录类型：

- 饮食：建议填写克数。
- 如厕/排便：建议填写次数和状态。
- 体重：填写 kg，会同步体重曲线和当前体重。
- 疫苗/驱虫：记录时间和备注。
- 照片：填写照片路径，进入时间线和相册。
- 备注：记录训练、情绪、睡眠等观察。

## 4. AI 教练

在「今天」页点击「生成今日建议」。

- 没有配置 key 时，会返回本地规则建议。
- 配置 `.env` 中的 `OPENAI_API_KEY` 后，会从服务端生成建议。
- 所有健康相关建议不能替代兽医诊断。

## 5. 费用和相册

- 「洞察」页可以新增费用并查看统计图。
- 「相册」页可以新增照片路径或未来的 R2 URL。

## 6. 提醒

「我的」页可以新增提醒并启用/停用。MVP 暂时只做应用内提醒计划，不触发系统推送。
