# PetDaily 使用说明

## 1. 初始化

本地开发：

```bash
npm install
cp .env.example .env
npm run db:push
npm run db:seed
npm run dev
```

访问 `http://127.0.0.1:3000`。

Cloudflare D1 上线：

```bash
nvm use
npx wrangler login
npm run cf:d1:create
```

把输出的 `database_id` 写入 `wrangler.jsonc` 后执行：

```bash
npm run cf:d1:migrate
npm run cf:d1:seed
npm run cf:deploy
```

部署完成后，用手机打开 Cloudflare 输出的线上 URL。线上数据会写入 D1，不依赖本机 `data/petdaily.db`。

## 2. 默认样例

seed 数据会创建一只 3 个月西高地幼犬「豆包」，并写入：

- 宠物档案和头像。
- 近两周体重记录。
- 喂食、如厕、排便、疫苗、驱虫和照片时间线。
- 喂食、外出如厕和驱虫提醒。
- 主粮、尿垫、玩具、医疗、护理费用。
- 一条初始 AI 建议。

## 3. 日常记录

进入「今天」或「记录」，点击「记录刚发生的事」或「新增记录」。

支持的记录类型：

- 饮食：建议填写克数。
- 如厕/排便：建议填写次数和状态。
- 体重：填写 kg，会同步体重曲线和当前体重。
- 疫苗/驱虫：记录时间和备注。
- 照片：填写照片路径，进入时间线和相册。
- 备注：记录训练、情绪、睡眠等观察。

删除初始模拟记录：进入「记录」页，点击每条记录右侧的「删除」。删除体重记录会重新计算当前体重；删除照片记录会同步删除相册里的关联照片。

## 4. AI 教练

在「今天」页点击「生成今日建议」。

- 没有配置 key 时，会返回本地规则建议。
- 配置 `.env` 中的 `OPENAI_API_KEY` 后，会从服务端生成建议。
- 所有健康相关建议不能替代兽医诊断。

## 5. 费用和相册

- 「洞察」页可以新增费用并查看统计图。
- 「相册」页可以点击「手机拍摄」调用手机相机，或点击「读取相册」选择已有照片。
- 照片会在浏览器端压缩后保存到 Cloudflare D1。照片数量变多后，下一步建议迁移到 R2。
- 每张照片都可以删除；删除通过相册创建的照片时，会同步删除对应的照片时间线。

## 6. 提醒

「我的」页可以新增提醒、完成今天、暂停/启用、删除提醒。首页会显示提醒状态：

- 已到点：当前时间已经超过提醒时间，且今天尚未完成。
- 稍后：提醒时间还没到。
- 今日已完成：今天已经点过完成。
- 已暂停：提醒暂时不参与待办。

当前版本是应用内提醒，不做系统级推送；手机打开网页即可使用和同步。
