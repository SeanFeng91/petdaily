# PetDaily 迭代路线

## V0.1 当前 MVP

- 单人单宠。
- 本地 SQLite。
- 时间日记、体重、费用、照片、提醒。
- 时间轴首页和可配置快捷事件。
- 体重、费用已有条目修改和删除。
- AI 本地 mock fallback + 可选在线模型。
- 手机优先、PC 兼容。

## V0.2 记录体验增强

- 记录筛选和日历视图。
- 排便状态结构化：形态、颜色、异常备注。
- 幼犬训练计划：定点如厕、坐下、召回、笼内安静。
- 快捷事件同步到账号/数据库，支持多端共享配置。

## V0.3 Cloudflare 同步

- D1 保存结构化数据。已接入 Worker 运行时的 `DB` binding。
- R2 保存照片。
- Cloudflare Workers 部署 Next.js 应用，手机端打开线上 URL 即可使用。
- 多端登录和同步状态提示。

## V0.4 AI 深化

- 周报/月报：体重、饮食、排便、费用和训练规律。
- 异常趋势保守提醒：食欲下降、排便异常、体重波动。
- 疫苗/驱虫计划自动复核。
- 用户可追问 AI，但保留非医疗诊断边界。

## V0.5 狗叫声检测与校准

- 前台监听工作台：麦克风权限、开始/停止、灵敏度、当前响度和疑似狗叫强度。
- 疑似狗叫自动写入时间线，关联短音频片段、持续时长、检测分数和聚类 ID。
- 声音库：保存候选音频、声学特征、embedding、简易波形和聚类状态。
- 主人反馈闭环：确认狗叫/误报、给相似声音组批量标注原因，减少逐条判断负担。
- 图表分析：按时间段、场景、原因标签、处理动作统计狗叫规律。
- 技术边界：Web/PWA 阶段只承诺前台运行；锁屏后台长期监听进入原生 App 或固定采集设备评估。

## V0.6 声学模型深化

- 音频特征和 embedding 增强：在现有响度、频谱变化、过零率、embedding 基础上引入更强的 MFCC/预训练模型特征。
- 服务端音频分类：区分狗叫、环境噪音、人声、门铃等误报来源。
- 个性化意图预测：结合声音向量、喂食/外出/训练历史和主人反馈，输出概率与解释。
- 模型评估面板：准确率、误报率、漏报率、不同标签样本量。
- 摄像头辅助：接入视觉线索，识别是否靠近门口、食盆、主人，是否踱步或警觉，再与叫声相似性融合。

## V0.7 家庭协作与交流

- 多宠物。
- 家庭成员共享记录。
- 照片日记分享。
- 可选的养宠经验交流区。
