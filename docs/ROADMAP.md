# PetDaily 迭代路线

## V0.1 当前 MVP

- 单人单宠。
- 本地 SQLite。
- 时间日记、体重、费用、照片、提醒。
- AI 本地 mock fallback + 可选在线模型。
- 手机优先、PC 兼容。

## V0.2 记录体验增强

- 常用记录模板：早餐、晚餐、饭后如厕、睡前如厕。
- 记录筛选和日历视图。
- 排便状态结构化：形态、颜色、异常备注。
- 幼犬训练计划：定点如厕、坐下、召回、笼内安静。

## V0.3 Cloudflare 同步

- D1 保存结构化数据。已接入 Worker 运行时的 `DB` binding。
- R2 保存照片。
- Cloudflare Workers 部署 Next.js 应用，手机端打开线上 URL 即可使用。
- 多端登录和同步状态提示。

## V0.4 AI 深化

- 周报/月报：体重、饮食、排便、费用和训练规律。
- 异常趋势保守提醒：食欲下降、排便异常、体重波动。
- 疫苗/驱虫计划自动复核。
- 用户可追问 AI，但保留非医疗诊断边界。

## V0.5 家庭协作与交流

- 多宠物。
- 家庭成员共享记录。
- 照片日记分享。
- 可选的养宠经验交流区。
